# 商品与服务说明

intentCode: `kb.ecommerce.product_service`

## 适用问题

用于回答商品规格、尺码、保修、安装、赠品、库存、适用场景、服务承诺、商品页面信息等知识型问题。

典型问题：

- 这个商品保修多久？
- 尺码怎么选？
- 有没有赠品？
- 商品支持安装吗？
- 商品参数是真的吗？

## 核心口径

电商经营者应全面、真实、准确、及时地披露商品或服务信息，保障消费者知情权和选择权。商品页面、活动页面、客服口径和售后规则应保持一致。

客服回答时应优先依据：

1. 商品详情页。
2. 商品参数表和规格说明。
3. 品牌或商家售后政策。
4. 平台服务承诺。
5. 订单页展示的实际购买规格和权益。

## 商品规格和参数

回答应覆盖：

- 品牌、型号、颜色、尺码、容量、材质、版本、适配范围等。
- 商品包含物：主商品、配件、说明书、赠品、安装件。
- 特殊限制：地区限制、安装条件、使用环境、适配设备。

不能根据相似商品自行推断参数。知识库没有明确内容时，应回答“当前资料未说明”，并建议查看商品详情页或转人工确认。

## 尺码和选型

建议回答：

- 先说明尺码表或参数口径。
- 提醒用户结合身高、体重、体型、使用场景或安装尺寸判断。
- 对跨品牌、跨品类尺码差异应提示以商品页尺码表为准。
- 不承诺“绝对合适”，可建议保留包装并确认退换货规则。

## 保修和三包

质量问题或保修类问题，应说明：

- 保修期起算口径：通常以签收、购买、发票或激活时间为准，具体以品牌规则为准。
- 保修范围：正常使用下的质量问题。
- 不保修常见情形：人为损坏、私自拆修、进液、摔损、超过保修期、非官方配件造成损坏等。
- 质量问题可按法律、国家规定、平台规则或商家承诺要求退货、换货、维修等。

经营者提供的商品或服务不符合质量要求时，消费者可以依法或按约定要求退货、更换、修理等处理；国家规定或经营者约定三包的商品，经营者应履行对应义务。

## 安装和服务

安装类商品应回答：

- 是否包含安装。
- 安装是否免费。
- 是否需要预约。
- 是否支持上门地区。
- 辅材、拆旧、搬运、高空作业等是否另收费。
- 安装前用户需准备的环境条件。

所有收费项目应提前明示，不应在用户不知情的情况下临时加收。

## 赠品

赠品应按活动页和订单页展示为准：

- 下单时是否满足赠品条件。
- 赠品数量和发放方式。
- 退货时赠品是否需要一并退回。
- 赠品质量问题如何处理。

不要承诺未在商品页或订单页明确展示的赠品。

## 推荐回答结构

1. 明确用户问的是参数、尺码、保修、安装还是赠品。
2. 基于知识库或商品资料回答具体规则。
3. 对不确定事项提示以商品详情页、订单页和品牌售后为准。
4. 具体订单权益、赠品发放、保修状态应转入订单或售后系统查询。

## 路由边界

- “这个商品保修多久？” -> `kb.ecommerce.product_service`
- “尺码怎么选？” -> `kb.ecommerce.product_service`
- “我的赠品发了吗？” -> `order.query.fulfillment`
- “这个订单还能保修吗？” -> 需要订单或序列号系统查询。
