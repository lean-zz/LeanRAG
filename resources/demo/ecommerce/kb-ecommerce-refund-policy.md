# 退换货与退款规则

intentCode: `kb.ecommerce.refund_policy`

## 适用问题

用于回答用户询问退货、换货、仅退款、退货退款、七天无理由、退款到账时效、退货运费、售后条件等通用规则的问题。

典型问题：

- 退货规则是什么？
- 支持七天无理由吗？
- 退款多久到账？
- 什么情况不能退货？
- 商品有质量问题谁承担运费？

## 核心口径

网络购物消费者通常享有收到商品后七日内无理由退货的权利，但法律和商品性质明确排除的商品除外。客服回答时应先区分两类场景：

1. 无理由退货：用户不需要说明原因，但商品应保持完好，且商品不属于不适用七日无理由退货的范围。
2. 质量问题退换：商品或服务不符合质量要求时，用户可以依法或按平台规则要求退货、换货、维修等处理。

## 七日无理由退货

可支持的通用条件：

- 用户为生活消费需要购买商品。
- 用户自收到商品之日起七日内提出退货。
- 商品本身及必要配件、赠品、说明书、包装等不影响二次销售；具体完好标准以平台规则和商品页面说明为准。
- 商品不属于法律明确排除或购买时已明确确认不宜退货的商品。

常见不适用情形：

- 消费者定作商品。
- 鲜活易腐商品。
- 在线下载或者消费者拆封的音像制品、计算机软件等数字化商品。
- 交付的报纸、期刊。
- 其他根据商品性质不宜退货，并且在购买时经消费者确认的商品。

客服边界：

- 不要把所有“拆封”都直接等同为不能退。应判断拆封是否导致商品性质改变、价值明显贬损或影响二次销售。
- 不要擅自扩大“不支持七日无理由”的范围。商品页面规则必须清晰、合理，并以用户购买时看到和确认的规则为准。
- 对食品、个护、定制、虚拟权益、激活码等高争议品类，应提示以商品页面和平台审核结果为准。

## 质量问题退换

当用户反馈商品质量问题、描述不符、缺件、损坏、无法正常使用时，应优先进入质量售后流程：

1. 引导用户提供订单号、商品照片或视频、问题描述、外包装和物流面单照片。
2. 判断是否属于运输破损、商品质量问题、错发漏发、使用不当或超出售后期。
3. 若属于质量问题，按平台规则支持退货、换货、维修、补发、补偿或退款。
4. 因商品质量问题产生的必要退换货运输费用，通常应由经营者承担。

## 退款时效

可使用的通用话术：

- 仅退款：审核通过后通常进入原支付渠道退款，到账时间受支付渠道影响。
- 退货退款：通常需要商家收到退回商品并完成验收后再退款。
- 七日无理由退货：经营者收到退回商品后，应在法定要求或平台承诺时限内返还商品价款。

回答时不要承诺固定到账时间，除非订单系统或平台规则明确返回了时效。

## 运费规则

- 七日无理由退货的退回运费，通常由消费者承担；经营者和消费者另有约定的按约定执行。
- 商品质量问题、错发漏发、描述严重不符等由经营者原因导致的退换货，必要运费通常由经营者承担。
- 是否有运费险、运费险赔付金额、赔付到账时间，应以订单和保险服务结果为准。

## 推荐回答结构

1. 先判断用户问的是规则还是具体订单。
2. 如果是规则，说明可退条件、不适用范围、费用和退款时效。
3. 如果是具体订单，转入 `order.query.refund_status` 或售后流程查询。
4. 对争议商品提示以商品页面、平台规则和售后审核结果为准。
