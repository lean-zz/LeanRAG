# 订单地址修改查询

intentCode: `order.query.address_change`

route: MCP `order_query`, `queryType=address`

## 适用问题

用于用户查询具体订单是否还能修改收货地址、联系电话或配送信息。

典型问题：

- 这个订单能不能改地址？
- 地址填错了怎么办？
- 收货手机号能改吗？
- 已发货还能改地址吗？

## 必要槽位

优先需要：

- 订单号。
- 用户身份或登录态。
- 新地址或需要修改的字段。

可选：

- 收货手机号后四位。
- 详细地址所在省市区。

## 路由动作

调用 MCP 工具：

```json
{
  "tool": "order_query",
  "queryType": "address",
  "orderId": "<order_id>"
}
```

## 回答口径

按订单状态判断：

- 待支付或待发货：通常有机会修改地址，但要以订单系统是否开放修改为准。
- 已拣货、已出库、已发货：通常无法直接修改平台订单地址，可尝试联系承运商改派或拦截。
- 已签收：无法修改本次配送地址。
- 预售、定制、大件、冷链、跨境等特殊订单：按商品和承运规则处理。

## 处理步骤

1. 查询订单当前履约状态。
2. 判断系统是否支持自助修改。
3. 如果支持，提示用户核对省市区、详细地址、收件人和手机号。
4. 如果不支持，说明原因并提供可选方案：联系承运商、申请拦截、取消重拍或转人工。

## 风险提示

- 地址修改可能影响配送时效。
- 改派不一定成功，成功与否以承运商反馈为准。
- 不要在公开聊天中展示完整手机号和详细地址。

## 不应做的事

- 不在没有订单状态时承诺能修改。
- 不直接要求用户在普通聊天中发送完整敏感地址；应引导到安全表单或人工受理渠道。
