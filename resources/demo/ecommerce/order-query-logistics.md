# 物流状态查询

intentCode: `order.query.logistics`

route: MCP `order_query`, `queryType=logistics`

## 适用问题

用于用户查询具体订单物流轨迹、快递单号、预计送达、签收状态和配送异常。

典型问题：

- 我的订单到哪了？
- 快递单号是多少？
- 什么时候送到？
- 物流怎么不更新？
- 显示签收但我没收到。

## 必要槽位

优先需要：

- 订单号。
- 用户身份或登录态。

可选：

- 快递单号。
- 收货手机号后四位。
- 收货地址城市。

## 路由动作

调用 MCP 工具：

```json
{
  "tool": "order_query",
  "queryType": "logistics",
  "orderId": "<order_id>"
}
```

## 回答口径

有物流结果时：

1. 告知订单当前物流状态。
2. 给出承运商和快递单号。
3. 给出最近一条轨迹。
4. 如有预计送达时间，明确说明是预计。
5. 如有异常，说明下一步处理动作。

没有订单号时：

- 先请用户提供订单号，或提示登录后选择订单。

物流异常时：

- 长时间不更新：建议等待承运商同步，同时可发起物流核查。
- 已签收未收到：核查签收人、签收地点、驿站、门卫或代收人。
- 破损或短少：引导保留照片、视频、外包装和面单。

## 不应做的事

- 不在没有系统结果时编造物流轨迹。
- 不承诺准确送达时间。
- 不直接承诺赔付金额。
