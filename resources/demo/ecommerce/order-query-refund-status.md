# 退款售后进度查询

intentCode: `order.query.refund_status`

route: MCP `order_query`, `queryType=refund`

## 适用问题

用于用户查询具体订单退款进度、退货退款状态、售后审核结果和平台介入进度。

典型问题：

- 我的退款进度到哪了？
- 售后审核通过了吗？
- 退货退款处理到哪了？
- 平台介入有结果吗？
- 钱什么时候退回来？

## 必要槽位

优先需要：

- 订单号。
- 售后单号或退款单号。
- 用户身份或登录态。

可选：

- 支付渠道。
- 退货物流单号。
- 商品名称。

## 路由动作

调用 MCP 工具：

```json
{
  "tool": "order_query",
  "queryType": "refund",
  "orderId": "<order_id>"
}
```

## 回答口径

有售后结果时：

1. 告知当前节点：待审核、待退货、待商家收货、验货中、退款中、已退款、已拒绝、平台介入中等。
2. 告知下一步需要谁处理：用户、商家、平台、支付渠道。
3. 给出可操作建议：上传凭证、寄回商品、填写物流单号、等待支付渠道到账等。
4. 对到账时间使用“预计”“通常”“以支付渠道为准”等表述。

审核被拒时：

- 说明拒绝原因。
- 告知用户可补充凭证、重新申请或申请平台介入。

没有售后单时：

- 提示当前订单未查询到售后申请，可引导用户进入售后规则或发起申请。

## 不应做的事

- 不承诺一定退款成功。
- 不跳过系统状态直接判断责任。
- 不把规则问题误判为具体订单查询。
